# Warning confound audit

This audit uses the canonical 400-episode benchmark's out-of-fold probe predictions. It asks whether warning scores distinguish failures from successes within the same suite/task group or mainly encode between-task difficulty.

Key result: step-0 action-expert and VLM scores are mostly task-structured and nearly chance within task. By step 100, both representations strongly rank failures within the same task, while task-attributable variance decreases. Action-uncertainty scores do not show outcome-specific growth.

The original CSV files are generated by `scripts/audit_warning_confounds.py`. These are post-hoc diagnostics, not a preregistered causal estimate. The completed bootstrap, held-out-suite, cross-condition, and richer-history extension is recorded in `reports/offline_robustness_gate/`.
